# RuleTrip v0.2.0 — Canary Packs & Evidence Comparison

RuleTrip v0.2.0 expands the original harness-canary engine without changing its central claim: RuleTrip proves only the observed response of a configured guard to a declared planted violation at a specific commit.

## Highlights

- five bounded canary-pack families: test, type-check, lint, workflow-pin, and repository policy;
- side-effect-free multi-guard discovery with `ruletrip init --dry-run`;
- `ruletrip presets` for inspecting shipped mutation templates;
- JUnit XML evidence alongside Markdown, JSON, and SARIF;
- stable v1 JSON Schemas for configuration and reports;
- cross-commit report comparison with optional regression exit status;
- continued zero-runtime-dependency design and disposable-worktree execution model.

## Upgrade

```bash
npm install --save-dev github:Dean00dev/RuleTrip#v0.2.0
```

Existing configuration schema version 1 remains valid. Review newly generated starter configs because v0.2 can discover more than one guard.

## Security boundary

No v0.2 feature turns the disposable Git worktree into an OS sandbox. Repository-configured commands remain trusted code, `pull_request_target` remains refused, and persisted reports continue to omit command stdout/stderr by default.
